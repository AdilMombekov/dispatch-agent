# Промт на аудит + редизайн Dispatch (v2)

> Самодостаточный промт. Дай его свежему агенту Claude Code в репозитории `E:\dispatch`.
> Сначала он проводит АУДИТ текущего состояния, потом проектирует и поэтапно строит
> v2 под нужды владельца. НИЧЕГО не удалять до утверждения плана.

---

## Контекст (что есть сейчас)

Windows-tray агент на Python (`E:\dispatch`), управляет ПК из Telegram. n8n/Railway
удалены. В этой сессии добавлено (ветка `chore/stabilize-and-cleanup`):
- Оркестратор `agent/orchestrator/` — очередь (SQLite `tasks.db`), Dispatcher,
  router, исполнители: qa (Haiku API), code (claude CLI), click_gui (computer-use),
  reviewer (Sonnet-гейт), budget (дневной лимит), scheduler (cron).
- Telegram-бот `agent/telegram_bot.py` — команды `/q /c /click /tasks /dispatch
  /every /daily /clean /login` и меню 2×2 (Чат/Коворк/Код/Настройки).
- Стабильность: single-instance mutex, watchdog debounce, ротация логов, backup-daemon.

Железо владельца: RTX 5060 **8 ГБ VRAM**, Intel Ultra 7 265KF (20 ядер), 32 ГБ RAM,
Win 11 Pro, Docker 29.4.

## Ограничения / принципы

- НИЧЕГО не удалять из репозитория и с диска до утверждения плана владельцем.
- Каждое изменение — отдельный коммит, синтаксис-проверка, тесты где можно без живого экрана/денег.
- Деструктивные действия любых агентов — только через `trash/` (мягкое удаление), даже в v2.
- Не автоматизировать вход в Google/сторонние сервисы (запрет владельца принят).
- Локальные модели: честно про 8 ГБ VRAM, без обещаний «несколько GPU-VM».
